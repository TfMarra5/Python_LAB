# Class Dashboard

## Project

For the supplied student grade records, implement averages, a set of students with average >=6, and a ranking excluding students with no grades. Sort by descending average, then ascending name. Also return the set of students without grades. Preserve input; use a comprehension and lambda.

## Expected Results

Ana 9, Caio 6, Rui 5.5; Bia has no grades. Ranking: Ana, Caio, Rui. Ties sort by name.

Implement the project in `main.py` and record your checks in `notes.md`.

Hint: Use a tuple sort key: negative average, then name.
