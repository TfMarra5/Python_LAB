# Course Enrollment Sets

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

For Python={Ana,Bia,Caio} and C={Bia,Davi}, calculate union, intersection, both differences, and symmetric difference. Convert a list with duplicates to a set and test an empty set.

## Expected Results

Union has four names; intersection Bia; differences Ana,Caio and Davi; symmetric difference Ana,Caio,Davi. Order is irrelevant.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
