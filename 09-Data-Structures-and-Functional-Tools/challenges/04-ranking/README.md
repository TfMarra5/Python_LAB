# Sort Without Losing the Original

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement ranking(scores), returning a new list in descending order with duplicates preserved. Keep the input unchanged. Also count the maximum, or report no scores.

## Expected Results

[7,10,7,5]→[10,7,7,5], max once; [8,8] twice; []→no scores.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
