# Fixed Coordinates

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement squared_distance(point_a, point_b) for 2D coordinate tuples. Return squared x difference plus squared y difference. Do not modify tuples; explain why tuple assignment fails.

## Expected Results

(0,0),(3,4)→25; equal points→0; (-1,-2),(2,2)→25.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
