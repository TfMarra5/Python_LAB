# Pair Names and Scores

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement pair_data with list(zip(names,scores)) and a dictionary built from the pairs. Names are unique. Test lists of different lengths and explain what is left out.

## Expected Results

Two names/two scores pair normally; two names/one score produce one pair and one entry.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
