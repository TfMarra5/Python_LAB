# Transform and Filter

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Use map and lambda to convert Celsius values to Fahrenheit; use filter and lambda to keep temperatures below zero. Convert both results to lists. Do not use loops or comprehensions.

## Expected Results

[-10,0,20]→[14.0,32.0,68.0] and [-10]; empty input→two empty lists.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
