# One Problem, Three Styles

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement three functions that return squares of even integers in original order: a for loop, a list comprehension, and map/filter/lambda. Do not mutate the input. Compare the results.

## Expected Results

[1,2,3,4]→[4,16] in all versions; [-2,0,2,2]→[4,0,4,4]; no evens→[].

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
