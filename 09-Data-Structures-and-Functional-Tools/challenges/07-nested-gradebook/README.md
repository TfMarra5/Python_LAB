# Nested Gradebook

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Given nested student records, implement average_student and add_grade. Return None for missing students or empty grades; adding a grade succeeds only for an existing student.

## Expected Results

Ana [8,6]→7; Rui empty→None; add 10 to Ana→True and average 8; unknown student→False.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
