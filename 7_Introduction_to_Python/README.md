## Como estudar

Leia o enunciado, escreva a previsão, implemente, execute e confira os casos. As pistas ficam recolhidas no final do enunciado. Use [progresso.md](progresso.md) para acompanhar a aula. Antes de começar, veja as [observações sobre os slides](../docs/observacoes-sobre-slides.md).

Da pasta Python_LAB, execute por exemplo:

```powershell
python 7_Introduction_to_Python/desafios/01-primeiro-programa/main.py
```

O arquivo inicial ainda não imprime nada: cabe a você escrever o programa. Não precisa de pacotes externos para os 12 desafios.
