# Lesson 7 — Python Fundamentals

The lessons cover Python execution, identifiers, types, references, operators, input/output, conditionals, and loops.

This lesson contains progressive challenges and an integrative project. The Python files are starting points, not solutions.

## Challenges

| 04 | [Packing Parts](challenges/04-division-and-remainder/README.md) |

Open each challenge README, make your attempt in `main.py`, and record your work in `notes.md`. Run a file from the repository root with `python <path-to-main.py>` or `py <path-to-main.py>` on Windows.

The final project is in the `projects` folder. [The optional Pandas exercise](../09-Data-Structures-and-Functional-Tools/bonus/pandas-apply/README.md) is available for lesson 9.
