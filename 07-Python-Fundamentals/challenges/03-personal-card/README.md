# Personal Greeting

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Read a name and a non-negative integer age. Print a greeting and the person’s age next year using an f-string. Assume valid input. Do not define your own functions.

## Expected Results

Ana, 20 → greeting for Ana and age 21. Rui, 0 → age 1. Age 99 → 100.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
