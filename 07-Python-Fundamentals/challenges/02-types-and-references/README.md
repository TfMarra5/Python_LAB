# Type Detective

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Create values 42, 3.5, True, "42", and None; print each value and its type. Use isinstance to check 42 and "42" against int. Reassign an integer variable to a string. Record id before and after without predicting the numeric IDs. Use dir("Python") and identify two method names.

## Expected Results

42 is int; 3.5 is float; True is bool; "42" is str; None is NoneType. isinstance(42,int) is True; isinstance("42",int) is False. id numbers vary.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
