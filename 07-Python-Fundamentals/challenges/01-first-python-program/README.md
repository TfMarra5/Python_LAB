# From C to Python

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Print the two lines “Hello, Python!” and “I am practicing Lesson 7.” In notes.md, explain how to run a .py file, what indentation does, and one difference between the usual ways of running C and Python programs. Classify total_score, 2total, class, _value, age, and Age as valid or invalid identifiers, and explain whether age and Age are the same name.

## Expected Results

No input is needed. The two messages appear on separate lines in the same order each time.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
