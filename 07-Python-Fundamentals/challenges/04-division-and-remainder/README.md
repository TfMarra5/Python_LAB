# Packing Parts

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Read a non-negative number of parts and a positive box capacity. Print full boxes, remaining parts, and the minimum boxes needed. Use //, %, and a conditional.

## Expected Results

17, capacity 5 → 3 full, 2 left, 4 needed. 15,5 → 3,0,3. 0,5 → 0,0,0.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).

<details>
<summary>Hint — open after trying</summary>

An extra box is needed only when the remainder is not zero.
