# Ticket Price

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Read a non-negative age and student status ("yes" or "no"). Under 13: free. Ages 13–17: 6 euros. Adults who are students: 8 euros; other adults: 12 euros. Use if/elif/else and logical operators.

## Expected Results

12/no → 0; 13/no → 6; 17/yes → 6; 18/yes → 8; 18/no → 12.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
