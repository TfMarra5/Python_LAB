# Cafeteria Cashier

## Project

Build a repeated menu: coffee €2, sandwich €5, water €1, or finish. Validate positive integer quantities; invalid choices must not ask for quantity. At the end print total units and cost. Use variables, conditionals, and loops only.

## Expected Results

Two coffees and one sandwich→3 units, €9; finish immediately→0 and €0; invalid quantity does not change totals.

Implement the project in `main.py` and record your checks in `notes.md`.

Hint: Separate choice, validation, and total updates.
