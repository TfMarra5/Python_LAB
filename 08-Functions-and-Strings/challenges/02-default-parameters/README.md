# Configurable Delivery Fee

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement total_cost(amount, fee=5), returning their sum. Call it with the default, an explicit fee, and named arguments in reverse order. The function must not read input or print.

## Expected Results

(20)→25; (20,0)→20; (fee=3,amount=10)→13.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).

<details>
<summary>Hint — open after trying</summary>

The default applies when an argument is omitted, not when it is zero.
