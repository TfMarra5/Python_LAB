# Search and Replace

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement first_position(text, part) with find and replace_text(text, old, new) with replace. Search is case-sensitive; replace all non-overlapping matches.

## Expected Results

banana/na→2; Python/py→-1; replace Java twice→Python twice; absent text stays unchanged.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).

<details>
<summary>Hint — open after trying</summary>

A result of 0 means a match at the start; -1 means no match.

</details>
