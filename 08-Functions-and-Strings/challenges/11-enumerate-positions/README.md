# Character Positions

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement show_positions(text, target), printing each matching index on its own line using enumerate. If there are no matches, print “Not found”. Case-sensitive; target is one character.

## Expected Results

banana/a→1,3,5; Ana/a→2; empty or absent→Not found.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
