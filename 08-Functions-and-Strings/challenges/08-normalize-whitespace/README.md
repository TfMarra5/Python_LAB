# Normalize Whitespace

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement normalize_spaces(text), trimming edges and replacing runs of spaces, tabs, or newlines with one space. Use split() and join(); preserve case and punctuation.

## Expected Results

"  I   study Python  "→"I study Python"; tabs/newlines become spaces; whitespace-only→empty.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
