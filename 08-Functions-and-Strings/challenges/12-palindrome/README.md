# Palindrome Rules

**Level:** Progressive practice · **Reference:** lesson slides.

## Challenge

Implement is_palindrome(text): ignore ordinary spaces and case only. Keep punctuation and accents. Return False for empty normalized text; otherwise compare it with its reverse. Add a docstring; keep input and print outside the function.

## Expected Results

Arara→True; A sacada da casa→True; Python→False; spaces only→False; arara!→False.

## Your Work

Implement your answer in [main.py](main.py). Record predictions and results in [notes.md](notes.md). Check the examples and add one of your own. From this folder, run `python main.py` (or `py main.py` on Windows).
