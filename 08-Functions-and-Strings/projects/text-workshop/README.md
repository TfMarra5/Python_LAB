# Text Workshop

## Project

Build a menu to normalize whitespace, count vowels, or check palindromes, plus quit. Put each operation in its own function; functions return values. Only the menu handles input/output. Reuse the lesson rules.

## Expected Results

Normalize repeated spaces; count AEiou as 5; Arara is a palindrome; spaces-only is False. Invalid choices do not ask for text.

Implement the project in `main.py` and record your checks in `notes.md`.

Hint: Test each function before connecting the menu.
