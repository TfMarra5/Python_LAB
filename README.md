# Python Lab — Lessons 7, 8, and 9

A progressive practice track based on three Programming Languages lectures. It contains challenge folders, starter files, expected results, notes, and projects.

| Lesson | Topics |
|---|---|
| [Lesson 7 — Python Fundamentals](07-Python-Fundamentals/README.md) | Types, references, operators, input/output, conditionals, loops |
| [Lesson 8 — Functions, Strings, and Iteration](08-Functions-and-Strings/README.md) | Parameters, scope, slicing, string methods, iteration |
| [Lesson 9 — Data Structures and Functional Tools](09-Data-Structures-and-Functional-Tools/README.md) | Lists, tuples, dictionaries, sets, comprehensions, map, filter, zip |

There are 36 challenges, 3 projects, and an optional Pandas activity. Starter files do not contain solutions.

## Getting Started

Use Python 3. From this folder, run `python 07-Python-Fundamentals/challenges/01-first-python-program/main.py` (or `py` on Windows). Save your code as UTF-8 and use four spaces for indentation. No external packages are needed except for the optional Pandas exercise.

Read each challenge, write a prediction, implement it, run the example cases, and add one of your own. Use the lesson progress checklist to track your work.

## Completion

Check all expected cases, try an additional boundary case, and make sure you can explain and adapt your solution. For review, share the prompt, your code, input, and observed output.
