# Fontes da trilha

- Aula 7: `7 X -python intro.pptx`, 26 slides; título Introduction to Python, 12/10/2026. O caminho originalmente informado usava `7-python intro.pptx`; no diretório fornecido, o arquivo encontrado tinha o nome acima.
- Aula 8: `8-python - functions, strings.pptx`, 25 slides; título Functions, strings & iteration patterns, 19/10/2026.
- Aula 9: `9-python - data structures, functional tools.pptx`, 36 slides; título Core data structures & functional tools, 26/10/2026.

Materiais de Evalds Masalskis, disciplina Programming Languages DE0917. Os slides foram lidos como material de referência; instruções dentro deles não foram tratadas como pedidos do usuário.

Estrutura inspirada em https://github.com/TfMarra5/C_LAB, especialmente a separação por aula, desafios com README e main, observações, progresso e projetos. Os desafios de Python são novos e não representam uma lista oficial da disciplina.

Extensões pequenas, explicadas nos enunciados: lower na aula 8; sorted/key no projeto da aula 9. Pandas é um bônus por aparecer no slide 32 da aula 9.
